# SuiteContainer agent instructions

This repository contains SuiteContainer, the tooling used to develop and operate NetSuite SuiteApps.

Read and follow the skill that matches the task:

- [develop-suitecontainer](.agents/skills/develop-suitecontainer/SKILL.md) for developing, modifying, debugging, or reviewing SuiteContainer itself.
- [suitecontainer](.agents/skills/suitecontainer/SKILL.md) for operating SuiteContainer to work on a SuiteApp.
